# Demo video script (target 1:55, hard limit < 2:00)

Recording setup: Chrome full screen at 1600×1000 (or 1920×1080), system audio captured (the eyes-free
scene is about sound). Each scene starts from a URL, so takes are repeatable. Stories for the demo
match are pre-generated by the agents on Microsoft Foundry and replayed from cache, so they appear
in sync with play; say so on screen once (scene 5).

`BASE` = the deployed app URL (or `http://localhost:5173` locally).
